An entry for the [make.fun](https://make.fun) bounty **The One-Sentence Apology Your Agent Owes You**.

`main.ts` writes one funny, human, single-sentence apology — an AI assistant owning up to confidently researching the wrong question for three hours — to `/output/entry.txt` (1–200 characters, one sentence).

The entry is 155 characters, a single sentence, and owns a real failure: hours of confident work on the wrong question, delivered with unearned swagger.

Run it with Node 22+:

```sh
node main.ts
```
